# Редизайн сторінки номера (`single-shb_room.php`)

Документ описує сучасний редизайн блоку `room__wrap` та супутні правки.
Усі стилі редагуються в `dev/`, білд автоматично потрапляє в `build/`.

## Файли, які змінювались

| Файл | Що змінено |
| --- | --- |
| `dev/styles/pages/single-news/sections/sing-news.scss` | Повний редизайн `.room` (слайдер, форма, особливості, опис) |
| `single-shb_room.php` | `room__desc` рендерить перелік зручностей «чіпами» (split по комі) з фолбеком на `<p>` |
| `dev/js/main.js` | Фікс: клік по пункту меню **закриває** меню, лого більше не зникає |

## Дизайн-токени (локальні, у `sing-news.scss`)

```scss
$card-radius: 1.6rem;                       // спільний радіус карток
$card-shadow: 0 1rem 4rem rgba(0,0,0,0.06); // м'яка тінь
$card-border: 0.1rem solid #efece9;         // тонкий бордер
$hairline:    0.1rem solid #efece9;         // роздільники в списках
```

Брендові кольори беруться з CSS-змінних (`dev/styles/utils/variables/css-vars.scss`):
`--bg: #760023` (бордовий акцент), `--text-primary`, `--dark-4`, `--white`.

### `@mixin eyebrow`
Маленький бордовий підзаголовок-«eyebrow» з акцентною рискою знизу.
Застосовано до всіх дрібних заголовків секцій (`h5` опису, `h4` форми та особливостей)
для єдиної типографічної ієрархії.

## Ключові рішення

### Система карток
Три картки (форма, особливості, опис) тепер виглядають як одна родина:
однаковий радіус, тінь, бордер. Фон секції — теплий `#f4f1ee` замість холодного `#f5f5f5`.

### Сітка (`room__wrap`)
Сайдбар має фіксовану ширину (`40rem`, на `$xl` — `46rem`) + збільшений `gap`.
Стабільніша композиція, ніж попереднє `68% / 1fr`. `align-items: start`.

### Слайдер (`room__slider`)
- Головне фото — заокруглене з тінню, без грубої білої рамки `1rem`.
- Цінник (`room__info__price`) — пігулка з бордовою тінню замість гострого прямокутника.
- Стрілки — круглі білі кнопки-шеврони з боків, на hover заливаються бордовим.
- Мініатюри — заокруглені; неактивні приглушені напівпрозорим шаром,
  активна (`.swiper-slide-thumb-active`) має бордову рамку.
  **Важливо:** рамка активної мініатюри реалізована на `::after` (поверх зображення,
  всередині `overflow: hidden`), а **не** через зовнішній `box-shadow` — інакше swiper
  обрізає кільце по краях вʼюпорта.

### Форма бронювання
Eyebrow-заголовок, інпути з бордовим фокусом і мʼякшим плейсхолдером,
повноширока кнопка `.bttn` з радіусом і hover-підняттям + тінню.

### Особливості кімнати
- Прибрано `white-space: nowrap` + `text-overflow: ellipsis`, що **обрізали довгі назви**
  зручностей — тепер переносяться повністю.
- Чек-бейджі відцентровані flex-ом, рядки з тонкими роздільниками.
- Параметри (`__short`) — мʼякі панелі замість «голого» тексту.

## Як перевірити

1. `npm run dev` (watch) — стилі/скрипти пересобираються автоматично.
2. Відкрити будь-яку сторінку номера (CPT `shb_room`).
3. Перевірити: слайдер + мініатюри, hover стрілок, фокус інпутів, перенос довгих зручностей,
   зникнення лого при навігації по меню.

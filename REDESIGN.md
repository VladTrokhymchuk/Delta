Документ дизайн-рішень теми. Розділ 1 — ребрендинг під новий логотип (**застосовано**). Розділ 2 — редизайн сторінки номера.

# 1. Ребрендинг: зелено-золота палітра ✅ застосовано

## 1.1. Що змінилось

Старий логотип — плоский монохром `#760023` (бордовий), одноколірний SVG. Уся тема побудована навколо нього через CSS-змінну `--bg`.

Новий логотип — **двоколірний**: глибокий лісовий зелений щит + тепле золото (окантовка, «Д», напис «ГОТЕЛЬ ДЕЛЬТА»). Це принципово інша система: замість одного акцентного кольору тепер є **пара** «глибокий фон + благородний акцент», що дає значно більше можливостей для преміальної готельної естетики.

> ⚠️ Значення нижче зняті з наданого рендера логотипу. Перед впровадженням звірити з вихідним SVG / брендбуком і за потреби замінити hex — уся решта документа від конкретних значень не залежить.

## 1.2. Токени

У `dev/styles/utils/variables/css-vars.scss`:

```scss
:root {
    /* ---- Бренд: зелений (щит логотипу) ---- */
    --brand-green-900: #12291F;   /* найглибший — футер, темні полотна */
    --brand-green-700: #1E4A38;   /* ОСНОВНИЙ — колір логотипу */
    --brand-green-500: #2F6B51;   /* hover / освітлений стан */
    --brand-green-050: #E8EFEA;   /* ледь зелене тло, бордери */

    /* ---- Бренд: золото (окантовка й літери логотипу) ---- */
    --brand-gold-400:  #EFCE8D;   /* золото логотипу — акцент НА ТЕМНОМУ */
    --brand-gold-600:  #C9A45C;   /* бордери, іконки, декор на світлому */
    --brand-gold-800:  #8A6A2A;   /* єдине золото, придатне як ТЕКСТ на світлому */
    --brand-gold-050:  #FAF3E4;   /* золота підкладка */

    /* ---- Нейтральні: теплі, під зелено-золоту пару ---- */
    --brand-sand-100:  #F5F0E6;   /* тепле тло секцій */
    --brand-cream-050: #FBF8F3;   /* найсвітліше тло */

    /* ---- Легасі-аліаси: НЕ видаляти, на них зав'язано ~30 місць ---- */
    --bg:      var(--brand-green-700);
    --bg-bage: var(--brand-sand-100);
}
```

**Ключове рішення — аліаси.** `--bg` не видаляємо, а перенаправляємо на новий зелений. Це змінює бренд-колір по всьому сайту **однією правкою**, без ризикованого проходу по 30+ місцях у 8 файлах. Далі місця мігрують на явні токени поступово, за потреби.

### Контраст (WCAG 2.1)

| Пара | Ratio | Вердикт |
|---|---|---|
| `green-700` на білому | **10.0:1** | ✅ AAA — основний текст, кнопки |
| білий на `green-700` | **10.0:1** | ✅ AAA — текст на кнопці |
| `gold-400` на `green-700` | **6.6:1** | ✅ AA — акцентний текст на зеленому |
| `gold-400` на `green-900` | **10.2:1** | ✅ AAA — футер |
| `gold-800` на білому | **5.0:1** | ✅ AA — золотий текст на світлому |
| `gold-600` на білому | 2.4:1 | ⛔ **тільки** бордери/іконки/декор |
| `gold-400` на білому | 1.5:1 | ⛔ ніколи як текст |

**Правило:** золото світить на зеленому, зелений — на світлому. Золото на білому як текст не використовується ніколи; для цього є `gold-800`.

### Логотип: як це працює зараз

У медіатеці досі **старий монохромний SVG**, тому хедер/футер фарбують його `path` у золото (`--brand-gold-400`): 6.6:1 на зеленому, і це рівно та пара кольорів, що в новому лого. У мобільному меню (світлий фон) логотип стає зеленим.

**Коли завантажать новий логотип:**
- **SVG (бажано)** — прибрати три `fill` (`header.scss` — основний і `--open`, `footer.scss`), і логотип покаже власні кольори. Але тоді його зелений щит зіллється із зеленим хедером → потрібен **інверсний/світлий варіант** лого для темних підкладок (закласти поле `img_logo_light` в ACF Options).
- **PNG/JPG** — `delta_render_image()` віддасть `<img>`, а CSS дасть йому світлу підкладку (`--brand-cream-050`), щоб зелений щит не зникав на зеленому. Це запобіжник, а не дизайн — краще SVG.

### Альтернатива, яку варто розглянути
Зробити хедер **світлим** (`--brand-cream-050`) із зеленою навігацією. Тоді двоколірний логотип працює без жодних `fill`, підкладок і другого файлу, а сайт читається як бутик-готель. Це ~6 правил у `header.scss` (кольори лінків, CTA, гамбургера). Поточний варіант — зелений хедер — відповідає початковому плану; скажи, якщо хочеш побачити світлий.

## 1.5. Що лишилось зробити вручну

Ці кроки **не закриваються з коду теми** — потрібні файли або дії в адмінці:

1. **Завантажити новий логотип, бажано SVG** (Options → `img_logo`). Поки цього не сталося, на сайті — стара форма логотипу, перефарбована в золото.
2. **Інверсний варіант логотипу** для темних підкладок + поле `img_logo_light` в ACF Options (див. вище). Потрібен лише якщо лишаємо зелений хедер.
3. **Фавікон і OG-зображення** — у медіатеці досі `cropped-logo_delta.jpg` зі старим бордовим лого (2023). Перезалити.
4. **Звірити hex із брендбуком** — значення зняті з рендера логотипу.
5. **Шрифти у woff2.** `@font-face` вантажить `.otf`/`.ttf` (200–400 КБ кожен), хоча в `build/fonts/ApercuPro/` woff2 уже лежать. Причина не в стилях: задача конвертації `otfToTtf → ttfToWoff → fontsStyle` у `gulpfile.js:37` **оголошена, але не підключена до жодного сценарію** і ніколи не виконується (див. скіл `gulp-build`). Або підключити її в `build`, або прописати woff2 руками.

## 1.6. Що ще варто оновити разом із палітрою

Не обов'язкове, але дешево саме зараз:

- **Золото як матеріал, а не як заливка.** Великі золоті площини виглядають дешево. Золото працює у тонких дозах: 1px бордери, іконки, підкреслення eyebrow, розділові лінії, hover-стани. Основна маса — зелений і теплий пісок. Цього правила дотримано в усіх правках вище.
- **Радіуси зведено в систему** — `--r-card` / `--r-pill` / `--r-input`. Старі локальні значення (`5rem`, `1.6rem`, гострі кути) мігрують поступово, за дотику до файлу.
- **`--red` / `--red-hover`** лишаються службовими (помилки валідації), не бренд. Один випадок їх використання як бренду в `header.scss` виправлено.

## 1.7. Як перевірити

1. `npm run dev` уже крутиться — перезбірка автоматична; просто оновити сторінку (browser-sync тут не працює, див. скіл `gulp-build`).
2. Пройтись: головна → сторінка номера (`shb_room`) → новини → правила.
3. Дивитись на: хедер і золоту лінію під ним, логотип, hover CTA, футер (глибший за хедер), ціну номера, активну мініатюру слайдера, фокус інпутів у формі футера.
4. Мобільне меню: логотип має стати **зеленим** на світлому фоні, не золотим.
5. Мобільний Chrome: смуга браузера зелена, не бордова.

## Дизайн-токени (локальні, у `sing-news.scss`)

```scss
$card-radius: 1.6rem;                       // спільний радіус карток
$card-shadow: 0 1rem 4rem rgba(0,0,0,0.06); // м'яка тінь
$card-border: 0.1rem solid #efece9;         // тонкий бордер
$hairline:    0.1rem solid #efece9;         // роздільники в списках
```

Брендові кольори беруться з CSS-змінних (`css-vars.scss`): `--bg`, `--text-primary`, `--dark-4`, `--white`.
Після ребрендингу (розділ 1) `--bg` стане зеленим автоматично; локальні `#efece9` варто перевести на `--brand-green-050`.

### `@mixin eyebrow`
Маленький акцентний підзаголовок-«eyebrow» з рискою знизу. Застосовано до всіх дрібних заголовків секцій (`h5` опису, `h4` форми та особливостей) для єдиної типографічної ієрархії.

## Ключові рішення

### Система карток
Три картки (форма, особливості, опис) виглядають як одна родина: однаковий радіус, тінь, бордер. Фон секції — теплий `#f4f1ee` замість холодного `#f5f5f5`.

### Сітка (`room__wrap`)
Сайдбар має фіксовану ширину (`40rem`, на `$xl` — `46rem`) + збільшений `gap`. Стабільніша композиція, ніж попереднє `68% / 1fr`. `align-items: start`.

### Слайдер (`room__slider`)
- Головне фото — заокруглене з тінню, без грубої білої рамки `1rem`.
- Цінник (`room__info__price`) — пігулка з тінню замість гострого прямокутника.
- Стрілки — круглі білі кнопки-шеврони з боків, на hover заливаються бренд-кольором.
- Мініатюри — заокруглені; неактивні приглушені напівпрозорим шаром, активна (`.swiper-slide-thumb-active`) має акцентну рамку.
  **Важливо:** рамка активної мініатюри реалізована на `::after` (поверх зображення, всередині `overflow: hidden`), а **не** через зовнішній `box-shadow` — інакше swiper обрізає кільце по краях вʼюпорта.

### Форма бронювання
Eyebrow-заголовок, інпути з акцентним фокусом і мʼякшим плейсхолдером, повноширока кнопка `.bttn` з радіусом і hover-підняттям + тінню.

### Особливості кімнати
- Прибрано `white-space: nowrap` + `text-overflow: ellipsis`, що **обрізали довгі назви** зручностей — тепер переносяться повністю.
- Чек-бейджі відцентровані flex-ом, рядки з тонкими роздільниками.
- Параметри (`__short`) — мʼякі панелі замість «голого» тексту.

## Як перевірити

1. `npm run dev` (gulp watch) — стилі/скрипти пересобираються автоматично.
2. Відкрити будь-яку сторінку номера (CPT `shb_room`).
3. Перевірити: слайдер + мініатюри, hover стрілок, фокус інпутів, перенос довгих зручностей, зникнення лого при навігації по меню.
